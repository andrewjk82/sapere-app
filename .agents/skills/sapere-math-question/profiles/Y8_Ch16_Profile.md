# Chapter Profile: Year 8 Chapter 16
## Probability

Use ICE-EM Year 8 Book 2 sections 16A–16D: probability scale, equally likely outcomes, complementary events, “or” and “and”, two-way tables, and Venn diagrams. Probability = favourable outcomes / total equally likely outcomes. For expected frequency, multiply probability by number of trials. For “at least”, count all qualifying outcomes or use the complement.

Common errors: using the favourable count as denominator; treating impossible events as non-zero; and overlooking more than one outcome in “at least” questions.
