# Chapter Profile: Year 8 Chapter 16
## Probability

### Standard solution methodology
For finite sets, the union contains every distinct element in either set; the intersection contains only shared elements. In a Venn diagram, count each region once.

### Common student pitfalls
Counting the overlap twice in a union; including elements outside both sets.
