# Chapter Profile: Year 12 Advanced Chapter 3 — Curve-sketching using the derivative

## Core concepts
- Stationary points satisfy \(f'(x)=0\). Classify using the sign change of \(f'\) or \(f''\).
- On a closed interval, global extrema may occur at stationary points or endpoints.
- For optimisation, express the quantity as a one-variable function, differentiate, solve, and compare feasible candidates.

## Standard methodology
1. Differentiate and solve \(f'(x)=0\).
2. Evaluate \(f\) at each stationary point and use \(f''\) or sign changes to classify it.
3. For a restricted sketch, calculate intercepts and endpoint values and plot features in order.
4. For optimisation, form the objective function, differentiate, check the domain/endpoints, and state units.

## Pitfalls
- A stationary point is not automatically a maximum.
- Do not omit endpoints when the domain is restricted.
- In rectangle problems, express both dimensions from the diagram before maximising area.
