# Chapter Profile: Year 9 Chapter 2 — Pythagoras' Theorem and Surds

Source checked: *ICE-EM Mathematics Year 9 Book 1*, Chapter 2 (sections 2A–2I).

## Core concepts
- **2A Pythagoras:** for a right triangle, (c^2=a^2+b^2), where (c) is opposite the right angle.
- **2B Simplifying surds:** extract the largest perfect-square factor, e.g. (sqrt{12}=2sqrt3).
- **2C Addition/subtraction:** combine like surds only; simplify first.
- **2D Multiplication/division:** multiply coefficients and radicands, then simplify.
- **2E Special products:** use conjugates and difference of squares, including ((u+v)(u-v)=u^2-v^2).
- **2F Rationalising:** multiply numerator and denominator by a suitable surd or conjugate; keep the value unchanged.
- **2G–2H:** applications and denominators involving surds.
- **2I Irrational numbers and surds:** distinguish irrational values from integers, terminating decimals, and rational fractions; perfect-square roots are rational. Non-terminating recurring decimals are rational and can be converted to fractions.

## Solution method
1. Identify the relevant operation (classify, simplify, combine, multiply/divide, rationalise, or compare).
2. Rewrite each surd using factors or apply the matching identity.
3. Show the intermediate arithmetic explicitly and simplify the result.
4. Check classifications and comparisons using exact values; state restrictions when denominators occur.

## Common pitfalls
- Calling every square root irrational: √36 is rational because it equals 6.
- Combining unlike surds or adding radicands instead of coefficients.
- Forgetting to simplify a surd before combining it.
- Rationalising only the denominator without multiplying the numerator by the same factor.
- Treating a recurring decimal as irrational; recurring decimals are rational.
- Omitting excluded values that make an original denominator zero.
