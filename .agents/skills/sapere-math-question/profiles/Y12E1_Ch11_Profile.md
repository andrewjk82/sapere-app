# Y12 Extension 1 — Chapter 11: Trigonometric equations

Source: Cambridge Mathematics NSW Stage 6 Extension 1 Year 12 textbook, sections 11A–11C; supplementary MET3 T3 exam-style questions.

## Core concepts

- **Compound-angle equations (11A):** expand sine and cosine addition/subtraction identities, use double- or triple-angle identities, factor, and solve every resulting trigonometric factor over the full stated interval.
- **Sums of sine and cosine functions (11B):** rewrite \(a\sin x+b\cos x\) as \(R\sin(x+\alpha)\) or \(R\cos(x+\alpha)\). Match coefficients, calculate \(R=\sqrt{a^2+b^2}\), and use coefficient signs to determine the correct quadrant for the phase.
- **The t-formula (11C):** use \(t=\tan(\theta/2)\), \(\sin\theta=2t/(1+t^2)\), and \(\cos\theta=(1-t^2)/(1+t^2)\). Check where the substitution or original expressions are undefined.
- **Sinusoidal extrema:** after writing a model in amplitude-phase form, use the first admissible phase angle for a maximum or minimum and solve for the earliest allowed time.
- **Compound-angle applications:** label the component angles and right-triangle sides. Express the requested angle as a difference before applying the tangent subtraction identity.

## Standard solution methods

1. State the domain or interval and rewrite the equation using the relevant identity.
2. For a sum of sine/cosine terms, expand the target amplitude-phase form, match coefficients, calculate the amplitude, and determine the phase quadrant from both signs.
3. For a factored equation, solve every factor; convert reference angles to all solutions in the stated interval and remove duplicates.
4. For an amplitude-phase model, locate the first maximum/minimum by setting the phase equal to the first admissible extremum angle, then solve for time and check that a later cycle is not earlier.
5. For a geometry application, use a labelled diagram, calculate each tangent ratio as opposite over adjacent, substitute into the compound-angle identity, and simplify one line at a time.
6. Check each final angle against the original domain and equation.

## Common student pitfalls

- Losing the minus sign when expanding \(R\sin(x-\alpha)\) or \(R\cos(x+\alpha)\).
- Choosing the phase from \(\tan\alpha\) alone without checking the signs of both sine and cosine.
- Solving only one factor after applying the zero-product property.
- Reporting only the principal inverse-trigonometric value instead of all solutions in the interval.
- Including a boundary solution for an open interval, or excluding a boundary solution for a closed interval.
- Using a later sinusoidal maximum instead of the first non-negative one.
- Applying a tangent difference formula with the angles in the wrong order.
- Confusing the billboard height \(a\) with the total upper height \(a+h\).
- Forgetting that a half-angle substitution is undefined at some values of \(\theta\).

## Diagram and solution requirements

- Show unit-circle markers for representative solutions and label duplicate roots only once.
- For sinusoidal sketches, show the midline, range, first extremum coordinates, and a smooth curve. Never label x-intercepts when the prompt prohibits it.
- In geometry diagrams, place \(\theta\) inside the sector between its sightlines and put dimensions next to the correct sides. Use separate diagrams when component-angle labels would overlap.
- Keep hints and highlight notes concise, student-facing, English-language, and specific to the question.
