# Chapter Profile: Year 9 Chapter 12 — Probability

## Core concepts used in this batch
- Theoretical probability: `P(E) = favourable outcomes / total equally likely outcomes`.
- Impossible events have probability 0.
- Multi-stage experiments: list outcomes systematically or use a tree; each branch represents one stage.
- Expected frequency: `number of trials × probability of the event`.

## Solution method
1. Identify the sample space and the event being counted.
2. Count favourable outcomes and all equally likely outcomes.
3. For repeated independent stages, show the sample space/tree and count the outcomes that satisfy the event.
4. For an expected count, multiply trials by the single-trial probability and state that it is an expectation, not a guarantee.

## Common pitfalls
- Using the favourable count as the denominator instead of the total.
- Counting ordered multi-stage outcomes as if order did not matter.
- Confusing “at least” with “exactly”.
- Reporting a theoretical expected count as a certain result.
