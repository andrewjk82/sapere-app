# Chapter Profile: Year 11 Advanced Chapter 8 — Exponential and logarithmic functions

## Core concepts
- Rewrite powers with a common base before equating exponents.
- Exponential values satisfy \(a^x>0\); hence the range of \(c-a^{g(x)}\) has a strict endpoint at \(c\) when the exponential can approach zero but never equals zero.
- Logarithms require positive arguments. Use \(\log_a u=\ln u/\ln a\) and \(k\ln x=\ln(x^k)\) only when the domain permits it.

## Standard methodology
1. State base/domain restrictions.
2. For exponential equations, convert to a common base and solve the exponent equation.
3. For logarithmic equations, combine logs or convert to an exponential/algebraic equation.
4. Check every candidate in the original domain and state the final result.

## Pitfalls
- Do not equate exponents until the bases match.
- An exponential term approaches zero but never reaches zero.
- Reject algebraic roots that violate the logarithm's positive-argument restriction.
