# Chapter Profile: Year 9 Chapter 17 — Quadratic equations

Source checked: *ICE-EM Mathematics Year 9 Book 2*, Chapter 17 (sections 17A–17F), provided in the current project.

## Core concepts
- **17A–17C: Solving quadratic equations:** rearrange to zero, factorise, and use the zero-product rule. For a difference of squares, use \(a^2-b^2=(a-b)(a+b)\). For equations with a non-unit leading coefficient, factorise by splitting the middle term and grouping.
- **17D: Applications:** define a variable, translate the context into a quadratic equation, solve, and reject values that do not make sense in the context (such as negative lengths).
- **17E: Graphs of quadratics:** use a table or equation features to find intercepts, symmetry, and turning point; sketch a smooth parabola. The sign of the leading coefficient determines whether it opens up or down.
- **17F: Completing the square:** add and subtract the square of half the linear coefficient to obtain vertex form and solve when appropriate.
- **Transformations:** in \(y=a(x-h)^2+k\), the vertex is \((h,k)\); horizontal signs inside brackets reverse direction; the sign of \(a\) determines reflection and opening.

## Solution method
1. Identify the quadratic structure and move all terms to one side so the equation equals zero.
2. Factor using a common factor, difference of squares, monic factorisation, or splitting and grouping.
3. Apply the zero-product rule or square-root method, showing both roots.
4. Check denominator restrictions and contextual constraints; state only valid solutions with units.
5. For graph tasks, derive each intercept and turning point before plotting. Build the sample diagram progressively, highlighting each newly calculated feature; put the completed sketch only in the solution, never in the question card.

## Common student pitfalls
- Omitting one root after taking a square root.
- Forgetting to set the equation equal to zero before factorising.
- Using the wrong sign for a horizontal translation.
- Listing a negative length or time even though it is algebraically a root.
- Treating the y-intercept as the vertex unless the graph’s symmetry confirms they coincide.
- Giving decimal approximations when the question asks for exact intercepts.
