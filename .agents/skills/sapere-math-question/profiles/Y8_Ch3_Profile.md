# Chapter Profile: Year 8 Chapter 3
## Factors, indices and index laws

Use factorisation, prime factors, powers and index laws from ICE-EM Year 8 Book 1, sections 3A–3E. For powers with the same base, multiply by adding exponents and divide by subtracting exponents; a zero power is 1 (for non-zero base). Apply powers to products and quotients carefully. Keep numerical coefficients separate from variables.

Solution flow: name the index law; apply it to each base; simplify coefficients; state the simplified expression. Common errors: adding bases instead of exponents, subtracting in the wrong order on division, and applying an exponent to only part of a bracket.
