# Chapter Profile: Year 8 Chapter 3
## HCF, LCM and indices

### Standard solution methodology
For products of powers with the same base, add exponents; for quotients, subtract exponents. Keep numerical coefficients separate from variable powers.

### Common student pitfalls
Adding exponents in a quotient; multiplying exponents in a product; forgetting a variable with exponent 1.
