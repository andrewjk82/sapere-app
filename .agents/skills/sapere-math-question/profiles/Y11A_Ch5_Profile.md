# Chapter Profile: Year 11 Advanced Chapter 5 — Transformations and symmetry

Source: CambridgeMATHS NSW Stage 6 Mathematics Advanced, Chapter 5, 5A–5H, user-provided textbook PDF.

## Core concepts
- Sections 5A–5D transform known graphs by translations, reflections, and dilations and connect algebraic changes with graph changes.
- Section 5C tests even and odd symmetry through \(f(-x)=f(x)\) and \(f(-x)=-f(x)\).
- Section 5E defines absolute value as distance/magnitude, as a piecewise function, and as \(\sqrt{x^2}\). It applies transformations to absolute-value graphs and solves equations of the form \(|ax+b|=k\).
- Section 5F covers composite functions; 5G combines transformations; 5H studies continuity at a point.

## Standard method for Section 5E absolute-value equations
1. For \(|A|=k\), first check the sign of \(k\). If \(k<0\), there is no solution; if \(k=0\), solve \(A=0\); if \(k>0\), split into \(A=k\) and \(A=-k\).
2. Solve both resulting equations independently, showing each algebraic step.
3. Substitute each candidate into the original absolute-value equation and reject any value that fails.
4. State all solutions together, without losing the negative branch.

## Common pitfalls
- Treating \(|A|=k\) as only \(A=k\) and omitting \(A=-k\).
- Making a sign error when dividing an equation with a negative coefficient.
- Accepting a value without checking it in the original equation.
- Claiming an absolute value can be negative.
