# Y12 Extension 1 — Chapter 13: Differential equations

Source: Cambridge Mathematics NSW Stage 6 Extension 1 Year 12 textbook, sections 13A–13E.

## Core methods
- Read slope fields as local directional information. For separable equations, separate variables, integrate, apply the initial condition, and verify in the original equation.
- For applications such as Newton cooling, model the difference from ambient temperature with an exponential and use the initial condition to determine the constant.

## Common pitfalls
- Include the constant of integration and use the initial condition.
- Cooling models use the temperature difference from ambient, not the absolute temperature.
