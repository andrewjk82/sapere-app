# Chapter Profile: Year 12 Advanced Chapter 2
## Graphing techniques and transformations

### Core concepts and formulas
- For \(y=f(x-h)+k\), a point \((u,v)\) on \(y=f(x)\) maps to \((u+h,v+k)\).
- For \(y=f(ax+b)\), map the input by solving \(ax+b=u\); horizontal coordinates transform inversely to the inside scale.
- For \(y=c f(x)\), each point \((u,v)\) maps to \((u,cv)\). Negative \(c\) reflects in the \(x\)-axis; \(|c|\) gives the vertical scale.
- Transformations are applied in their stated order. For \(y=-[f(x)+k]\), translate first and reflect second.
- To solve \(f(x)>g(x)\) graphically, locate intersections and identify intervals where the graph of \(f\) lies above that of \(g\).
- For \(y=A+B\sin(kt)\) or cosine, the centre line is \(y=A\), amplitude is \(|B|\), and period is \(2\pi/|k|\) (or \(360^\circ/|k|\) in degrees).
- A sinusoid's range is \([A-|B|,A+|B|]\). A cosine beginning at its minimum has negative cosine coefficient.

### Standard solution progression
1. Mark the given point, intercepts, extrema, asymptotes, period, or graph symmetry that the question uses.
2. Convert each transformation into a coordinate rule or identify centre/amplitude/period.
3. Apply the transformations in the correct order; for inside changes solve for the new input coordinate.
4. Use the transformed features or equation to solve the requested equation/inequality, respecting open/closed endpoints and the stated domain.

### Common pitfalls
- Reversing the sign of a horizontal translation.
- Treating \(f(2x)\) as a horizontal stretch instead of a compression; solve the inside-input equation.
- Forgetting to transform both coordinates when a vertical and horizontal change occur together.
- Reflecting before/after a translation incorrectly when the question specifies the order.
- Using amplitude as the maximum value rather than the distance from the centre line.
- Reporting only one periodic solution when the restricted domain covers more than one cycle.
