# Chapter Profile: Year 8 Chapter 7
## Percentage applications

### Standard solution methodology
Convert percentages to decimals or fractions. A percentage change is (change/original)×100%. For successive percentage multipliers, multiply the corresponding decimal factors.

### Common student pitfalls
Using the new amount rather than original as denominator; adding percentages when a successive multiplier is needed.
