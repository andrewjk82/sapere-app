# Chapter Profile: Year 9 Chapter 6 — Formulas

## Core concepts used in this batch
- **6A Substitution into formulas:** replace each pronumeral by its given value, use brackets for negative values, then evaluate using order of operations.

## Solution method
1. Write the formula and list the supplied values.
2. Substitute each value in parentheses, especially negative values.
3. Evaluate powers first, then multiplication/division, then addition/subtraction.
4. Check signs and state the requested variable and units.

## Common pitfalls
- Substituting a negative number without brackets before squaring it.
- Treating `1/2 at²` as `(1/2 × a × t)²`; only `t` is squared.
- Reordering operations or dropping a negative sign.
