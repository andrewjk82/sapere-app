# Chapter Profile: Year 8 Chapter 8
## Pythagoras' theorem

### Standard solution methodology
For a right triangle, hypotenuse² = leg₁² + leg₂². Identify the side opposite the right angle before substituting; take the positive square root for a length.

### Common student pitfalls
Using a non-hypotenuse as c; subtracting in the wrong order; giving a negative length.
