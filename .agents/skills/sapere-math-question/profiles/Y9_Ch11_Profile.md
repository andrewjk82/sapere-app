# Chapter Profile: Year 9 Chapter 11 — Coordinate Geometry

## Core concepts used in this batch
- Distance between points: use horizontal/vertical differences; for general points use `d = √((x₂−x₁)²+(y₂−y₁)²)`.
- Gradient: `m = (y₂−y₁)/(x₂−x₁)`.
- Straight-line form: `y = mx + c`, where `m` is gradient and `c` is the y-intercept.
- A point and gradient determine a unique line; parallel non-vertical lines have equal gradients.
- Graphing a constant equation `y = k` gives a horizontal line through height `k`.

## Solution method
1. Identify whether the task asks for distance, gradient, equation, parallel line, or graph.
2. Substitute coordinates into the relevant formula and show the arithmetic.
3. For an equation, use `y = mx + c` or substitute the given point to find `c`.
4. Verify the equation with the supplied point(s); for a graph, plot enough correctly labeled points and draw the line.

## Common pitfalls
- Reversing only one coordinate difference in the gradient formula.
- Confusing gradient with y-intercept.
- Using the wrong point when solving for `c`.
- Drawing `y = k` as a vertical line; it is horizontal.
- For distance, forgetting to square both coordinate differences before adding.
