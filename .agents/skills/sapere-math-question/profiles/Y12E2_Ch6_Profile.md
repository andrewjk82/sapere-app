# Y12 Extension 2 — Chapter 6: Mechanics

Source basis: local Extension 2 curriculum map (Topics 6A–6G) and Abbotsleigh 2025 4U Trial with supplied solutions.

Topics: forces, simple harmonic motion, resisted motion, projectiles, and miscellaneous mechanics problems.

## Core methods
- Draw a force-direction model and set a consistent positive axis before applying Newton's second law.
- For resistance proportional to v², express acceleration as a function of velocity; use v dv/dx = a to integrate with respect to displacement.
- Terminal speed occurs when net force and acceleration are zero.
- For relative-motion and minimum-separation problems, write relative position and velocity vectors; minimize the squared separation with respect to time.

## Common pitfalls
- Resistance always opposes motion, so its sign changes with direction of travel.
- Distinguish velocity from speed and displacement from distance fallen.
- Apply initial conditions and select the physically meaningful root/time interval.
