# Chapter Profile: Year 9 Chapter 3 — Consumer Arithmetic

## Core ideas used in this batch
- **3B Using percentages:** find a percentage of an amount with `percentage / 100 × amount`. A commission or loading is a percentage of the stated base amount; for tiered commission, calculate each bracket separately and add.
- **3C Simple interest:** `I = Prt`, where `P` is principal, `r` is the annual rate as a decimal, and `t` is time in years.

## Solution method
1. Identify the base amount, rate, time, or price bracket from the wording.
2. Convert a percentage to a decimal and write the relevant calculation.
3. For tiered percentages, split the amount into the stated bands before calculating.
4. Add component amounts when required, include units/currency, and check the result is sensible.

## Common pitfalls
- Applying a rate to the whole amount when the question gives tiers.
- Treating a percentage such as 17.5% as 17.5 instead of 0.175.
- Confusing interest earned with the final balance; this batch asks for interest earned.
- For simple interest, multiplying by the number of years exactly once.
