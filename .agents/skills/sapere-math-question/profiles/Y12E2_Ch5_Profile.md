# Y12 Extension 2 — Chapter 5: Vectors

Source basis: local Extension 2 curriculum map (Topics 5A–5G) and Abbotsleigh 2025 4U Trial with supplied solutions.

Topics: 3D coordinates, vectors, dot product, dot-product applications, vector geometry proofs, line equations, and sphere/plane equations.

## Core methods
- Use coordinates and vector components in three dimensions; project parametric curves by eliminating the parameter and recording restrictions.
- Equidistance loci in 3D are perpendicular bisector planes; derive them by equating squared distances and simplifying.
- Use vector equations for lines, planes and spheres; use dot products for angles and perpendicularity.
- In regular tetrahedra/cubes, use symmetry and equal edge lengths to obtain vector dot products and angle relations.

## Common pitfalls
- Squaring both distances avoids unnecessary radicals but requires careful expansion.
- Projection onto a coordinate plane sets the omitted coordinate to zero.
- Keep track of vector direction and use the correct included angle in dot-product calculations.
