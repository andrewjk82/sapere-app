# Chapter Profile: Year 8 Chapter 13
## Congruence and special quadrilaterals

### Standard solution methodology
In a parallelogram, opposite sides are parallel and equal; a diagonal can create alternate interior angles and a shared side for a congruence argument.

### Common student pitfalls
Calling a pair of co-interior angles equal; omitting the parallel-line fact that justifies equal alternate angles.
