# Chapter Profile: Year 9 Chapter 19 — Statistics

## Core concepts used in this batch
- A stem-and-leaf plot organizes every data value while preserving the original data.
- Order data before locating the median. For an even number of values, average the two middle values.
- Mean: `sum of data values ÷ number of values`.

## Solution method
1. For a stem-and-leaf plot, sort values, split each into stem and leaf, and order leaves within each stem; include a key.
2. To find the median, order all observations and identify the middle position(s).
3. To find the mean, add all values and divide by the count; show the total and the count.
4. Check that the result is sensible relative to the data and use the requested rounding.

## Common pitfalls
- Omitting duplicate values when building a plot or calculating a statistic.
- Failing to order leaves or to provide a key.
- Selecting one middle value for an even-sized data set instead of averaging the two.
- Dividing the mean by the wrong number of data values.
