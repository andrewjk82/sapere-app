# Year 7 Mathematics Task 3, 2013 — Source Profile

## Source and scope
Willoughby Girls High School, Year 7 Mathematics Task 3 (2013), scanned source PDF. The paper contains a 30-minute non-calculator section (22 questions, 28 marks) and a 60-minute calculator section (Number 12 marks, Algebra 21 marks, Measurement 12 marks, Geometry 15 marks; 65 marks total). The separate 5-mark Working Mathematically strand is assessed through the reasoning in those questions, not added as new questions. Content is mapped into the existing Y7 topic files.

## Conversion rules
- Preserve every distinct source task and all subparts, source values, units, diagrams, and restrictions (including “show working” and “do not calculate actual division”). Retain open-response `review` items for explicit drawing/graphing tasks; include a visible sample answer and a final worked diagram where drawing is required. Convert explanatory tasks to multiple choice when a suitable set of reasoning options preserves the skill being assessed.
- Make determinate numeric and matching tasks four-option multiple choice where this does not remove an essential constructed response. Use plausible, mathematically distinct distractors and vary the correct option index. The app shuffles choices at presentation time.
- Write hints and student-facing solutions in clear English. Every question receives a question-specific hint and worked steps that show the relevant arithmetic, units, rule, and conclusion. Multipart items retain each original part and mark allocation.
- Use source diagrams as the basis for the stem figures. Add separate solution-step figures when a highlight, plotted point, factor tree, construction, or geometric relationship teaches the method. Inspect SVGs at student display size before publishing.

## Content map
- Non-calculator Number: place value and estimation; integer operations and order of operations; decimals; fraction/percentage conversion; symbols and revision; roots and powers; prime factorisation, HCF and divisibility.
- Calculator Number: recurring decimals, multiplication and money, unitary cost, negative temperatures, square roots, number line and Cartesian plane.
- Algebra: patterns and rules, substitution, simplifying like terms, brackets, powers, equations and word problems, perimeter equations.
- Measurement: graduated scales, speed/odometer, protractor reading, metric conversions, perimeter, elapsed time, time zones, 24-hour time.
- Geometry: adjacent and vertically opposite angles, triangle and quadrilateral angle sums, reflex and exterior angles, parallel-line reasoning, ellipse recognition, symmetry axes, prism cross-sections, and cuboid edge relationships.

## Mathematical checks and common errors
- For order of operations, evaluate brackets, multiplication/division, then addition/subtraction left to right. For 11 − (8 − 3) × 2 + 25 ÷ 5, the result is 6.
- The estimate in Number Q8 uses leading-digit rounding: 38,346 ≈ 40,000 and 16,097 ≈ 20,000, so the estimated difference is 20,000. (The handwritten key instead records 30,000 − 20,000 = 10,000, reflecting truncation to the first digit; the imported answer follows the source key's intended leading-figure convention.)
- Preserve the source key's exact results where clear. Correct obvious working slips while retaining the same question and result; e.g. solve x/5 + 3 = 7 by subtracting 3, then multiplying by 5.
- For the quadrilateral angle question, distinguish the 87° interior angle from the reflex angle c drawn around the outside of that same vertex; c=360°−87°. Identify the exact sector marked by each arc and keep labels inside that sector, close to the arc, without overlap.
- In a parallel-lines test, same-side interior angles must total 180°. In the source example 123° + 60° = 183°, so the lines are not parallel.
- A reflection or geometric drawing answer must show the finished object, not only describe the construction. The original figures must remain legible and correctly labeled.
