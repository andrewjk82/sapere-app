## Standard teaching method

### Equations
1. Name the unknown and translate the statement into an equation.
2. Use inverse operations on both sides, showing each intermediate equality.
3. For square equations, include both square-root solutions unless the problem restricts the domain.
4. Substitute the result back into the original equation to check it.

### Ratios, rates, and time
1. Convert quantities to matching units before comparing or simplifying.
2. For ratios, find the total number of parts or the unit value before scaling.
3. For a unit rate, divide the measured amount by its corresponding time/quantity and label units.
4. For travel graphs, a flat segment means a stop; speed is the gradient magnitude; read event times from the horizontal axis before calculating.

### Linear relationships and coordinate graphs
1. For tables, substitute each x-value and keep its y-value in the same column.
2. From a table, find the constant change in y for a one-unit change in x, then use the x=0 value for the intercept.
3. Plot ordered pairs by moving horizontally first (x), then vertically (y).
4. To find two lines' intersection algebraically, set their y-expressions equal, solve for x, substitute to find y, and check both equations. Show both lines and the exact intersection in the sample graph when the task asks students to draw them.

## Common student errors

- Doing operations on only one side of an equation, or distributing a factor to only one term.
- Giving only the positive root when solving `x^2 = k`.
- Comparing ratios or rates with mismatched units (hours/minutes, metres/centimetres).
- Dividing by the wrong ratio part when finding a unit share or unit price.
- Reading a stop as movement on a travel graph, or confusing distance from home with total distance travelled.
- Reversing ordered-pair coordinates, or assigning a point to a quadrant without checking both signs.
- Finding an intersection's x-coordinate but not substituting to obtain y.
