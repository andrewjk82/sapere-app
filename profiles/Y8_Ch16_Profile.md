# Year 8 Chapter 16: Probability

## 1. Core Concepts
This chapter introduces the foundational concepts of probability, focusing on finite sample spaces with equally likely outcomes, and extends into set operations using Venn diagrams and two-way tables.

### 16A: An introduction to probability
- **Sample Space ($X$ or $S$)**: The complete set of possible outcomes.
- **Event ($A$)**: A subset of the sample space.
- **Probability of an Event ($P(A)$)**: 
  - $P(A) = \frac{\text{number of favourable outcomes}}{\text{total number of outcomes}}$
- **Probability Range**: $0 \le P(A) \le 1$.
- **Complement ($A^c$ or $A'$)**: The event "not $A$".
  - $P(A^c) = 1 - P(A)$.

### 16B: 'Or' and 'and'
- **Intersection ($A \cap B$)**: The event that both $A$ AND $B$ occur.
- **Union ($A \cup B$)**: The event that either $A$ OR $B$ (or both) occur.
- **Addition Rule**: $P(A \cup B) = P(A) + P(B) - P(A \cap B)$.

### 16C: Two-way tables
- Reading and interpreting data from two-by-two tables.
- Calculating probabilities from marginal totals and cell values.

### 16D: Further uses of Venn diagrams
- Using Venn diagrams to sort and count elements.
- **Cardinality Rule**: $|A \cup B| = |A| + |B| - |A \cap B|$.
- Solving word problems involving 2 or 3 overlapping sets.

## 2. Standard Solution Methodology

### Simple Probability (16A)
1. **Identify the Sample Space**: List or count all possible outcomes.
2. **Identify Favourable Outcomes**: List or count the outcomes that satisfy the event's condition.
3. **Calculate**: Use the probability formula $P(A) = \frac{\text{favourable}}{\text{total}}$.
4. **Simplify**: Reduce the fraction to its simplest form.

### Complementary Events (16A)
1. **Identify Event $A$**: Sometimes it's easier to calculate the probability of an event NOT happening.
2. **Calculate $P(A)$**.
3. **Calculate $P(A^c)$**: Subtract from 1.

## 3. Common Student Pitfalls
- **Lazy Negatives**: In multiple-choice, students don't usually pick a negative probability because probability cannot be less than 0. Instead, they make errors in counting (e.g., miscounting primes: 1 is NOT a prime number).
- **Complement Error**: Forgetting to subtract from 1, or subtracting the numerator only (e.g., $1 - \frac{3}{10} \rightarrow \frac{2}{10}$).
- **Overlapping Sets Error**: When counting $A \cup B$, double-counting the intersection $A \cap B$.
- **Fraction Simplification**: Leaving fractions unsimplified or simplifying them incorrectly.
